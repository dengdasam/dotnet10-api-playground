04数学表达式求值 POST

POST /api/calculator    body: { "expression": "1+2*(3-4)/5" }
手写递归下降解析器，不执行任意代码、不引用第三方包。支持括号、四则、右结合幂运算、一元正负号、科学计数法与常用函数，参数错误返回明确中文提示。
也支持 GET /api/calculator?expression=...
尚未调用
点击「发送请求」查看响应。
支持的语法、函数与错误码
  • 运算符：+ - * / ^，括号 ()，一元正负号；^ 右结合，故 2^3^2 = 512。
  • 常量：pi（或 π）、e、tau（或 τ）；数字支持 1.5e2 这类科学计数法。
  • 单参函数：sqrt abs sin cos tan asin acos atan ln log log10 exp floor ceil round sign deg rad。
  • 双参函数：pow min max hypot；三角函数按弧度输入，角度用 rad(30) 转换。
  • 错误码：EMPTY_EXPRESSION、INVALID_TOKEN、UNMATCHED_PARENTHESIS、DIVIDE_BY_ZERO、MATH_DOMAIN_ERROR、UNKNOWN_FUNCTION、BAD_ARGUMENT_COUNT 等。

品种列表、密钥配置与降级策略
  • 密钥：服务端按 THECATAPI_KEY 环境变量 → 仓库根 .env.local 的顺序读取；两者都没有时使用官方公开匿名额度，响应 authenticated 会标明。密钥绝不写入源码或提交到仓库，/api/health 只暴露是否已配置、不暴露内容。

犬种列表、分组统计、缓存策略与数据许可
  • 免密钥：dogapi.dog 官方写明「No key, no sign up」，因此这套接口没有任何密钥配置项，/api/health 里的 dogApi 只报索引状态。
  • 索引三层：内存索引（命中即微秒级）→ 仓库种子 Data/dog-breeds.json（约 660 KB，首启与断网都能用）→ 运行时缓存 .cache/dog-breeds-v2.json（后台刷新成功后落盘，7 天内优先于种子）。上游全量响应 1.84 MB、国内实测单次 15~40 秒，所以冷启动不等上游，先出种子再后台换新。

  • 图片许可：图片来自 Wikimedia Commons，响应里的 attribution（author / license / licenseUrl / sourceUrl）是许可要求的一部分，页面预览已把作者与许可显示在图注里，二次使用时请保留。
  • 分组：AKC 9 个分组由索引聚合得出，不额外请求上游；分组 UUID 不可构造，服务端内置了映射表。

错误码一览（均以 success=false 返回）
  • INVALID_VALUE / INVALID_CATEGORY / INVALID_UNIT / MISSING_UNIT：单位换算入参问题；RATE_UNAVAILABLE：汇率数据不可用。
  • MISSING_CITY / INVALID_CITY：天气城市名缺失或过长。
  • EMPTY_EXPRESSION / INVALID_TOKEN / UNMATCHED_PARENTHESIS / DIVIDE_BY_ZERO / MATH_DOMAIN_ERROR：表达式解析与数学定义域问题。
  • INVALID_TIMEZONE / INVALID_DATETIME / MISSING_DATETIME：时区与时间格式问题。
  • INVALID_JSON：POST 请求体不是合法 JSON；INTERNAL_ERROR：未预期的服务端异常。
  • INVALID_LIMIT / INVALID_SIZE / INVALID_BREED / MISSING_BREED / INVALID_IMAGE_ID / MISSING_IMAGE_ID：猫咪接口入参问题。
  • CAT_API_KEY_INVALID / CAT_API_RATE_LIMIT：密钥被拒（401）或触发限流（429）；CAT_UPSTREAM_UNAVAILABLE：上游不可用且无缓存；CAT_NO_IMAGE / CAT_BREED_NOT_FOUND / CAT_IMAGE_NOT_FOUND：查询无结果。
  • DOG_BREED_NOT_FOUND / DOG_IMAGE_NOT_FOUND / DOG_NO_IMAGE / DOG_NO_FACT：狗狗查询无结果（名称不唯一时请改用完整英文名或 UUID）；DOG_UPSTREAM_TIMEOUT / DOG_UPSTREAM_UNAVAILABLE / DOG_UPSTREAM_ERROR / DOG_RATE_LIMIT：上游不可用或被限流；DOG_IMAGE_UNRESOLVED：上游未返回 Location 头。
注意：本服务面向本地演示，开放访问、未做鉴权与限流。天气上游为公开免 Key 服务，断网时返回的是模拟数据，不可用于生产决策；猫咪接口的密钥只存本地，响应里不会回传；狗狗图片来自 Wikimedia Commons，请按响应里的 attribution 保留署名。若需部署到公网，请补充鉴权、超时与限流策略，并改用服务端密钥注入而非本地文件。
